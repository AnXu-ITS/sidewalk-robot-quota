# 配额算法 v2 修订版 — 最终规则 + 7 城/香港 验证报告

**最终决策**：利用率优先。护栏边际 Δ 定为 **0**（去掉边际），过预测交给
Q_low / C(W) / floor 等既有护栏兜底。其余两处改动（宽路钳 3.0、复杂 C 取瓶颈）
保持不变，其它 OOD 门与冻结 v1 完全一致。

## 1. 最终规则（三处改动）

| # | 改动 | 内容 |
|---|---|---|
| 1 | 宽路不弃权 | `W>3.0` → A/B 钳 `W_eff=3.0`；C 型钳瓶颈宽度 |
| 2 | 复杂 C 不弃权 | `W_eff = min(width_p10, 3.0)` |
| 3 | **边际归零** | `Δ = 0.00`（所有宽度段一致） |

不变：`W_eff<1.6`、`q_p>60`、`x≥33.33`、弯道 B（sinuosity>1.05）、急弯 → 仍弃权；
`Q_low` / `C(W)` / `q_max=20` / floor 不变；名义幂律 `c·W_eff·(q_p/W_eff)^p` 不变。

## 5. 关键发现（如实）

1. **利用率大幅回升且过预测封顶**：7 城 68%（vs 20%）、香港 66.7%（vs 16.7%），
   约 3.4 倍。过预测 7 城 8%、香港 23.8%，**单格最多 +2~+3，无灾难性过给**。
2. **边际 Δ 冗余**：Q_low / C(W) / floor 已把过预测封顶在 ≤+3，Δ 再加只是白白牺牲
   利用率（Δ=3.1 要花 48 个点利用率才把 8% 过预测压到 0%）。
3. **恢复 cell 里"钳 3.0"始终保守**（D2 28 个 W>3.0 恢复 cell 过预测 0%），宽路安全。
4. **香港过预测更高（23.8% vs 8%）**：香港真实几何比 D2 合成矩形更难，且复杂 C 用
   瓶颈等效矩形近似本身有偏差；过预测仍都是 +2/+1 的小偏差。

## 6. 验证局限

- 复杂 C 型用**瓶颈等效矩形**（宽=width_p10 的 50m 直走廊）模拟，是容量近似，
  非真实路口几何。
- 小样本：香港 21 cell；D2 训练 5 城 / 留出 2 城。
- 合成人流（qp 为实验设定），非实测流量。
