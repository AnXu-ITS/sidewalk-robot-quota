# 配额算法 v2 正式规则（`V2_RULE.md`）

> 机器可读配置：`v2_quota_config.json`。实现：`v2_quota.py`。
> v2 相对冻结 v1（`final_freeze/final_operational_rule.md`）只改两处：
> **① 宽度解析（宽/复杂 C 不弃权）② 边际由全局改为按宽度分段**。其余全部继承。

## 输入

| 符号 | 含义 |
|---|---|
| `W` | OBB 长轴垂向截面的中位宽度（测量值，m） |
| `width_p10` | 瓶颈宽度 = 同截面宽度剖面的 10% 分位（m） |
| `q_p` | 行人流量（ped/min），合成实验需求 |
| `base_pass` | 基线是否通过（mean-based，见下） |
| `type` | 几何类型 A（直）/ B（弯）/ C（复杂多边形） |
| `sinuosity` / `max_turn_deg` / `cum_turn_deg` | 几何特征 |
| `vbar` | 基线（qr=0）行人平均速度（m/s） |

## 执行顺序

```
W_eff 解析 → OOD(窄/高x/弯B/急弯/超qp) → base_pass → 零护栏 → 名义公式 → 分段边际 → Q_low → q_max → floor
```

### ① W_eff 解析（v2 新增）

| 类型 | W_eff |
|---|---|
| A / B | `min(W, 3.0)` |
| C | `min(width_p10, 3.0)` |
| 任意 | `W_eff < 1.6` → **弃权 OOD** |

### ② OOD 门（→ 弃权 None，未变部分与冻结一致）

- `W_eff < 1.6` → 弃权（窄路下界未动）
- `q_p > 60` → 弃权
- `x = q_p / W_eff ≥ 33.33` → 弃权
- `type ∉ {A, B, C}` → 弃权
- `type = B` 且 `sinuosity > 1.05` → 弃权（弯道门未动）
- 急弯：`max_turn ≥ 20°` 且 `cum_turn ≥ 20°` 且 `max_turn/cum_turn ≥ 0.6` → 弃权

### ③ base_pass（mean-based，未变）

`base_pass = (mean_density ≤ 1.20) AND (0.90 ≤ mean_flow_ratio ≤ 1.20)`
（qr=0 的 30 种子均值；速度项在 qr=0 时为空，不计）。`base_pass=0` → 配额 0。

### ④ 零护栏（硬清零，未变）

- `q_p ≥ C(W_eff)` → 0；`C` 节点 `W[1.5,1.6,1.7,1.8,2.1,2.4,2.7,3.0] → C[10,35,35,45,45,55,90,90]`
- `vbar < 0.8` → 0

### ⑤ 名义幂律（未变）

$$\hat q_r = 24.374155890965095 \cdot W_{\text{eff}} \cdot \left(\frac{q_p}{W_{\text{eff}}}\right)^{-0.9454494315945483}$$

### ⑥ 边际 Δ（v2 定为零）

`q = max(0, q̂ − Δ)`，**Δ = 0.00**（所有宽度段一致）。

> 决策：利用率优先。7 城全规则扫描显示 Δ=0 时利用率中位 68.4%、过预测仅 7.8%
> 且全部 ≤+3（Q_low / C(W) / floor 已兜底）；Δ=3.1 要牺牲 48 个点利用率才能把
> 7.8% 过预测压到 0%，不划算。故边际取零，过预测交给既有护栏约束。

### ⑦ Q_low 上限（未变）

`q = min(q, Q_low(W_eff))`；`Q_low` 节点
`W[1.5,1.6,1.7,1.8,2.1,2.4,2.7,3.0] → Q[0,5,6,8,10,18,20,20]`

### ⑧ q_max 上限（未变）

`q = min(q, 20.0)`

### ⑨ floor（未变）

`q_r^op = floor(q)`

## 与 v1 的差异摘要

| 项 | v1 冻结 | v2 |
|---|---|---|
| W > 3.0 m | OOD 弃权 | A/B 钳 3.0；C 钳瓶颈 |
| 复杂 C 型 | OOD 弃权 | 按 width_p10 计算 |
| 边际 | 全局 3.1068 | 0.00（去掉边际，利用率优先） |
| W < 1.6 m | OOD | OOD（未变） |
| 弯道 B（sinuosity>1.05）/ x≥33.33 / 急弯 | OOD | OOD（未变） |

## 已知取舍（已接受）

- 边际取零 → 允许适度、且封顶的过预测：7 城 192 cell 过预测率 7.8%、单格最多 +3、
  合计 +20；香港 13 有效 cell 过预测 2 格（+2、+1）。换取利用率中位 68%（7 城）/
  56%（香港），远高于 v1 的 20%。
- "太宽→3.0"对楔形 A/B（OBB 宽但瓶颈窄，如 HK-ST-31）偏粗，忽略。
- 弯道 B 门（sinuosity>1.05）未放宽：HK-ST-32（宽且弯）仍弃权。
